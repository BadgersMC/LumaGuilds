## Native rendering limits

The HTML is a browser simulation, not a native-layout specification. Native
buttons cannot have independent per-button backgrounds or arbitrary row widths;
input is after body and before actions. Component links cannot guarantee an
arbitrary full rectangular click hitbox or a clickable native item image. Use
faithful content/order and available glyph art, and disclose these differences.
Exact glyph metrics/GUI scales, long labels and packet-order flicker require TEST
client acceptance, separately authorized. No push/PR/deployment/reload/restart.
