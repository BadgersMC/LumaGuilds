# LG-1204 scheduled increased XP — SPEAR

REQ-052: multiply applicable current-run XP before source-cap reservation, retaining
the configured cap and accepting at most its remaining allowance.

Use one operator-configured UTC interval with inclusive start and exclusive end,
a finite multiplier of at least one and an explicit source set. Default off;
default sources exclude administrative bonuses. Weekly quest XP may be included
and remains uncapped. Fractional XP is rounded down after multiplying the complete
award. Integer overflow rejects before persistence. Invalid enabled configuration
is rejected rather than silently applying an unintended rate.

Resolve the immutable boost configuration per accepted activity request, after
eligibility and anti-AFK checks. Evaluate the trusted server event timestamp so
the interval starts/expires automatically without a mutable scheduler toggle and
survives restart/reload. No XP, source-usage or reward-state rewrite occurs.

Tests must first fail for missing boost behavior, then prove boundaries, source
selection, rounding, validation, immutable settings, reload, rejection ordering,
fixed-cap partial final awards and durable duplicate handling.
