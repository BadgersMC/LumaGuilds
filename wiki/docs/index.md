# LumaGuilds

LumaGuilds 3 is the guild, progression, quest, war, and land-claim platform powering [EnthusiaSMP](https://enthusiasmp.com). Chapter 2 adds weekly guild quests, reward progression, prestige, seasonal war rating, and full Java/Bedrock menu parity. Pick where you want to go:

- **[Getting Started](getting-started/welcome.md)** — New to the server? Start here.
- **[Players](players/how-do-i.md)** — How everything works, organized by feature.
- **[Weekly Guild Quests](players/quests.md)** — Shared objectives, automatic rewards, and per-quest leaderboards.
- **[Progression](players/progression.md)** — Chapter XP, rewards, seasonal rating, and prestige.
- **[Admins](admins/installation.md)** — Install, configure, and integrate.
- **[Upgrading to 3.0](admins/upgrade-3-0.md)** — Major-version migration and rollout gates.
- **[Developers](developers/architecture.md)** — Code-level reference.

In-game, type `/g help` to get a clickable topic menu that mirrors this wiki.
